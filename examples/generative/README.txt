Generative Models
=================

Examples of generative models for functional data using diffusion models.

This directory contains a complete implementation of functional data generation
using latent space diffusion models, following the FunDiff architecture.

Requirements:
- PyTorch 2.0+: Install with `pip install torch` or `pip install scikit-fda[generative]`

Notebooks:
1. 01_functional_autoencoder_training.ipynb - Train encoder/decoder
2. 02_latent_diffusion_training.ipynb - Train diffusion model in latent space
3. 03_functional_generation_demo.ipynb - Complete generation pipeline demonstration

See README.md for detailed documentation and usage instructions.
